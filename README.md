A Python-based financial automation tool built to reconcile high-volume monthly bank statements against General Ledger records, automatically flagging unmatched transactions, pending cheques, and bank charges.
Matches thousands of debit and credit transactions using Pandas `merge` logic.
Categorizes discrepancies into **Matched**, **Amount Mismatch**, **Bank Only**, and **Ledger Only** audit tabs.
Reduces manual month-end reconciliation time by up to 70%.
